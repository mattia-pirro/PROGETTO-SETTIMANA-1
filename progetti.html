Pagina Ricetta

Tecnologie: HMTL5, CSS3, Git

Una pagina web che presenta una ricetta di cucina. Esercizio di markup semantico applicato a un contenuto reale: titolo principale, sezioni distinte per ingredienti e procedura, lista ordinata per i passaggi, immagine del piatto finale con didascalia.

Cosa ho imparato: scegliere il tag in base al significato del contenuto e non all'aspetto visivo. Differenza tra section e article. Uso di figure e figcaption per le immagini con didascalia.

Card di presentazione

Tecnologie: HMTL5, CSS3, font Awesome

Un biglietto dicitale con nome, ruolo, foto profilo e link ai social. Esercizio su tag semantici, link esterni con target="_blank", immagini con alt significativo. Prima esperienza con le icone Font Awesome.

Cosa ho imparato: organizzare l'informazione in poco spazio mantenendo gerarchia visiva. Uso degli id per anchor interne. Pattern header / main / footer su una seingola card.

Portfolio personale

Tecnologie: HMTL5, CSS3, Google Fonts, Font Awesome, Git, GitHub Pages

La pagina che state vedendo. Costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS Completa con box-model, pseudo-classi, pseudo-elementi e tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.

Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. stilizzare in modo consapevole partendo da un reset CSS. Gestire un Repository Git con Commit descrittivi. Pubblicare un sito statico online.
